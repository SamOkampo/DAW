# FLOWDAW 1.0.0-rc.1

FLOWDAW 1.0.0-rc.1 is the first frozen release candidate after completion of the Phase 0–14 product roadmap.

## What to validate

Test the packaged application, not a build-tree executable. Prioritize device setup, recording, save/reopen, FLOW Core content discovery, third-party plugin scanning/hosting, routing, mastering analysis and final export.

## Artifact integrity

Every candidate artifact should be paired with release metadata and SHA-256 checksums generated by `tools/release_manifest.py`. The commit in the manifest must match the candidate source commit.

## Release status

This candidate may be used for controlled validation. It must not be represented as a fully production-cleared 1.0 release until the distribution licence/JUCE compliance decision, platform signing/notarization and physical installed-app evidence are complete.

# Changelog

## 1.0.0-rc.1 — Release candidate

FLOWDAW's first release candidate freezes the completed Phase 14 technical baseline and adds release-readiness infrastructure.

Highlights include:

- production JUCE desktop across Linux, Windows and macOS;
- Arrangement, Step Sequencer, Smart Sampling/REC CHOPS, Piano Roll, recording, automation and advanced mixer/routing;
- realtime VST3 hosting and macOS AU hosting with project state persistence and PDC;
- FLOW Core first-party sounds, native instrument presets and starter sessions;
- native FLOW EQ, Compressor, Limiter, Saturator, Reverb, Delay, Chorus, Gate/Expander and Utility with preset support;
- autosave/recovery, plugin quarantine, Sample Browser and production workflow polish;
- offline mastering analysis, loudness/true-peak target workflow, PCM16/24 and Float32 WAV delivery with deterministic TPDF policy for integer reduction;
- release metadata/checksum tooling plus install, privacy, support, troubleshooting, signing and QA documentation.

The RC is not a final 1.0 distribution declaration until the owner/legal, signing/notarization and physical installed-app gates in `docs/RELEASE_CHECKLIST.md` pass.

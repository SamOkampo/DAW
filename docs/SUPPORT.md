# FLOWDAW Support Triage

Use a reproducible report containing:

- FLOWDAW version and commit if known;
- operating system/version;
- CPU architecture;
- audio interface/device, sample rate and buffer size;
- plugin format/name/version when relevant;
- exact reproduction steps;
- expected and actual behavior;
- whether the issue reproduces in a new FLOW Core starter project.

## Severity

- **Release blocker:** data loss, repeatable crash/hang in a normal workflow, corrupted save/reopen, broken install/launch, missing bundled content, invalid release artifact, or a security/privacy issue.
- **High:** major production path unavailable with a supported configuration and no reasonable workaround.
- **Normal:** localized defect with a workaround.
- **Enhancement:** new capability rather than a regression.

Do not include credentials, signing certificates, API keys or other secrets in issue reports.

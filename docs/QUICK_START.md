# FLOWDAW Quick Start

1. Launch the installed FLOWDAW application.
2. Open Settings / Audio and select a valid output device, sample rate and buffer.
3. Start from Blank or a FLOW Core starter such as Boom Bap, Trap or Lo-Fi.
4. Build drums in the Step Sequencer or import/preview samples from the Browser.
5. Use Piano Roll for native or external instruments.
6. Record audio by selecting an input, arming the intended track and enabling monitoring only when needed.
7. Route and mix from the Mixer; Track, Bus and Master each have their own rack target.
8. Use native FLOW effects or scan compatible VST3/AU plugins.
9. Save to `.flow`, close, reopen and confirm the project state before long sessions.
10. Use Master Analysis before delivery, then export Float32 or the EBU-oriented PCM24 + TPDF path as appropriate.

If a plugin repeatedly fails, use Plugin Maintenance or `flowdaw-doctor` rather than repeatedly forcing it into the realtime graph.

# FLOWDAW Privacy / Telemetry Statement

As of FLOWDAW 1.0.0-rc.1, the repository's production application does not implement a FLOWDAW account system, cloud project upload, advertising SDK, analytics SDK or product telemetry pipeline.

Projects, app settings, recovery snapshots, plugin safety state, favorites/recent samples and scanned-plugin information are handled locally by the application unless the user separately moves or shares those files.

Third-party plugins run under their own vendors' behavior and privacy terms. FLOWDAW cannot make privacy claims on behalf of a plugin loaded by the user.

This statement describes the current source baseline. Any future network, account, crash-reporting or telemetry feature must update this document before release.
